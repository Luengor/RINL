En este apartado se detallan los requisitos funcionales del sistema como casos de uso. Se han
definido tres paquetes de requisitos funcionales:
\begin{itemize}
    \item \textbf{Gestión de usuario}: Se agrupan aquí los casos de uso relacionados con la
           gestión de usuarios como la visualización y modificación de datos personales, así como
           aquellos relacionados con el registro y la sesión del usuario.
    \item \textbf{Estadísticas y seguimiento}: Se encuentran aquí los casos de uso referentes a la
           visualización de estadísiticas de juego y la historial de formas físicas.
    \item \textbf{Juego}: Se agrupan aquí los casos de uso relacionados con el juego en sí, como la
           selección de minijuegos, la calibración de la cámara y la interacción con los minijuegos.
\end{itemize}
