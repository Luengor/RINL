\chapter{Matriz de Rastreabilidad de Requisitos}
\label{anexo1:cap:matriz}
La matriz de rastreabilidad de requisitos relaciona cada uno de los requisitos del sistema (ya sean
funcionales, no funcionales o de información) con los objetivos del sistema. Se crean dos tablas:
una para los requisitos funcionales (Cuadro \ref{anexo1:tab:matriz:requisitos-funcionales}) y otra para
los requisitos no funcionales y de información (Cuadro
\ref{anexo1:tab:matriz:requisitos-info-nonfuncionales}).
