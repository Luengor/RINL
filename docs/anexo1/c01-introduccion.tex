\chapter{Introducción}
\label{anexo1:cap:introduccion}
En este documento se recoge la especificación del sistema, que incluye los requisitos funcionales,
no funcionales y de información, así como los casos de uso, distintos actores involucrados y,
finalmente, la matriz de trazabilidad de requisitos. La estructura de este documento sigue la
descrita por Durán y Bernárdez \cite{DuranBernardez}.
