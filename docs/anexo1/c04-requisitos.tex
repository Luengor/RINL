\chapter{Catálogo de requisitos del sistema}
\label{anexo1:cap:requisitos}
En este capítulo se expone el catálogo de requisitos del sistema, que incluye tanto los requisitos
funcionales como los no funcionales, así como los requisitos de almacenamiento de información.
También se incluyen los diagramas de casos de uso y la definición de los actores del sistema. Todo
esto siguiendo las pautas dadas por Durán y Bernárdez \cite{DuranBernardez}.

\section{Requisitos de almacenamiento de información}
\label{anexo1:sec:requisitos-almacenamiento}
