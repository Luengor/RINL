\section{Herramientas}
\begin{frame}{Herramientas}
    \small
    \begin{block}{Elección de herramientas}
        Las razones para escoger una herramienta sobre otra son distintas y
        particulares para cada una de ellas.  De manera general, se ha optado
        por herramientas con las que ya se tenía \alert{experiencia previa},
        tenían \alert{buena documentación y gran comunidad}, o simplemente
        parecían las \alert{más adecuadas para el proyecto}.
    \end{block}

    \begin{enumerate}
        \item Herramientas utilizadas en el \textit{backend}
        \item Herramientas utilizadas en el \textit{frontend}
        \item Herramientas utilizadas en el videojuego
        \item Herramientas utilizadas para el despliegue
    \end{enumerate}
\end{frame}
\normalsize
