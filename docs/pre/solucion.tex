\begin{frame}
    \frametitle{Base de datos}

    \centering
    \begin{columns}
        \column{0.6\textwidth}
        Para la aplicación se utiliza una base de datos relacional
        \textbf{PostgreSQL} para almacenar los \alert{datos de los usuarios, las
        actividades realizadas y sus formas físicas}. Puesto que muchos de estos
        datos son de carácter sensible, se utiliza encriptado \textit{at rest}
        para proteger la información almacenada.

% Limitaciones
\begin{frame}
    \frametitle{Limitaciones}
    \begin{itemize}
        \item La calidad de la detección de posturas depende en gran medida de
        la \alert{cámara utilizada y la iluminación del entorno}.
        \pause

        \item Para hacer posible el uso de la aplicación en dispositivos
        móviles, \alert{la calidad de la detección de posturas se reduce} en
        estos dispositivos.
        \pause

        \item \alert{No se utilizan calorías} para medir el esfuerzo físico,
        sino una \alert{unidad de medida propia y simplificada} que se basa en
        la cantidad de movimiento realizada por el usuario.

    \end{itemize}
\end{frame}
