\chapter{Descripción de la solución propuesta}
\label{cap:solucion}
En este capítulo se describe el producto final desarrollado en el proyecto. El objetivo de la
sección es demostrar el funcionamiento del producto final más que explicar los aspectos técnicos
e internos del sistema.

Para la descripción del producto final se ha optado por una estructura que sigue el flujo de
interacción de un nuevo usuario con el sistema. Se realizarán las labores básicas en la aplicación
web y posteriormente se describirá el funcionamiento de los videojuegos implementados. Se
utilizarán capturas de pantalla para ilustrar las distintas pantallas de la aplicación y se
explicará el funcionamiento de cada una de ellas. Para el videojuego, se realizará una breve
descripción de cada uno de los videojuegos implementados y se incluirán capturas de pantalla
y videos que muestren el funcionamiento de los mismos.

\section{Interacción con la aplicación web}
\label{sec:interaccion-web}
La aplicación web (desplegada actualmente en \url{https://rinl.soymilk.lueng.org}) es el punto de
entrada del usuario al sistema. Se le presenta al usuario una pantalla de inicio simple, que solo
contiene el título del proyecto y un botón y un formulario para iniciar sesión o registrarse. Para
cambiar entre las dos opciones, el usuario puede hacer clic en el botón de "Iniciar sesión" o "Registrarse"
según lo que desee hacer (ver figura \ref{fig:solucion:inicio-sesion} y \ref{fig:solucion:registro}).

Si el usuario ya ha iniciado sesión anteriormente, la aplicación web le mostrará una pantalla de
bienvenida con dos botones: uno para acceder a la página del usuario y otro para cerrar sesión
(ver figura \ref{fig:solucion:bienvenida}). Pulsar el botón de cerrar sesión muestra un mensaje
de confirmación y, si el usuario lo confirma, se cierra la sesión y se vuelve a la pantalla de
acceso al sistema.

En la página principal del usuario se muestra un menú lateral con varios botones que permiten
acceder a las distintas secciones de la aplicación web. Inicialmente, hasta que el usuario
verifique su correo electrónico, solo aparecen los botones para acceder a la página de
entrada al sistema, a la página de datos en la que se encuentra y un botón para cerrar sesión
(ver figura \ref{fig:solucion:usuario-sin-verificar}).

El usuario puede verificar su correo electrónico haciendo clic en el enlace enviado a dicho
correo durante el registro. Si por alguna razón el usuario no recibe el correo, puede solicitar
el envío de otro haciendo clic en el texto marcado en la imagen. Una vez que el usuario verifica
su cuenta, se muestra una notificación para informarle de que su cuenta ha sido verificada y se
muestra una sección adicional para añadir su forma física (ver figura
\ref{fig:solucion:usuario-verificado}). Haciendo clic en el botón de añadir forma física, se
muestra un formulario que el usuario debe completar con su peso y altura (ver figura
\ref{fig:solucion:anadir-forma}). Una vez que el usuario ha añadido su forma física, se
muestra una notificación para informarle de que se ha añadido correctamente y se muestra la
forma física añadida.

Tras verificar su cuenta, el usuario puede modificar algunos de sus datos personales como pueden
ser su nombre, apellidos, edad y correo electrónico. Para ello, el usuario simplemente debe editar
los campos del formulario y hacer clic en el botón de guardar cambios. Este botón solo se muestra
si el usuario ha modificado alguno de los campos del formulario, manteniéndose oculto la mayoría
del tiempo.

Cualquier cambio que no incluya modificar el correo electrónico se guardará de forma inmediata y se
actualizará la información mostrada en pantalla. Si el usuario desea cambiar su correo electrónico,
se mostrará una notificación para informarle de que se le ha enviado un correo electrónico a la
nueva dirección para que confirme el cambio (ver figura \ref{fig:solucion:usuario-modificar-correo}).

Una vez que el usuario ha añadido su forma física, se le muestra una sección adicional en el menú
lateral para acceder a la sección de estadísticas. En esta sección, el usuario puede ver un historial
de su forma física y las actividades que ha realizado. Si el usuario no ha realizado ninguna actividad
física (o si no se ha añadido ninguna forma física, aunque esta página es normalmente inaccesible en
ese caso) se muestran gráficos vacíos y un mensaje que indica que no hay datos disponibles (ver figura
\ref{fig:solucion:estadisticas-vacia}).

vez que ha añadido su forma física. Nada más acceder a esta sección, el navegador solicitará
permiso para acceder a la cámara web del usuario si no se ha concedido previamente. Una vez se
concede el acceso, se muestra el canvas sobre el que se mostrará el videojuego desarrollado en
Unity, un botón para activar la pantalla completa y lo capturado por su cámara web en una
esquina.
